How does the route finder work?

We use breadth-first search (BFS). It checks roads one step at a time, starting with the nearest junctions. Because every road segment has the same length in this model, the first route found is a shortest available route. Real navigation apps also consider traffic, speed limits and travel times.

GPS estimates where you are; a route-finding algorithm decides which roads to take. These are two different jobs working together.
